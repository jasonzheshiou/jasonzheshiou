Why a second edition exists

A pixel icon has to commit

A 1.7-px vector stroke can afford to be suggestive. At 32 × 32 with one pixel per mark, an icon is either legible or it is noise — there is nowhere to hide, which is the same discipline I apply to a claim in a study: strip the decoration and see if it still reads. Pixel art is also what the house style already implies: one of the repositories here is a pipeline where a model paints pixel art by writing code, so using its primitives for the site's own graphics is the honest thing to do.

How the conversion worked

  1. Read the vector sprite as geometry.The site's icon sheet is one inline <symbol> set; the converter parses it and flattens paths — curves and arcs sampled into polylines — so every shape becomes a list of points.
  2. Redraw it with pixel primitives at 32 × 32.Straight edges go through Pixel_Storybook's line() (Bresenham, one pixel per step) and circle() (midpoint), rects through the inclusive rect(). That is why the result is pixel art and not a resample: each lit cell is a whole pixel, decided by integer arithmetic.
  3. Throw out what breaks.Thin diagonals, dashes and 3-pixel circles turn to salt at this size: the shield, signature, ID card, agent diagram, trend-with-magnifier, black box, clock, particles and standard check were redrawn as character matrices instead — the same text-matrix path Pixel_Storybook uses when the model server has no vision tower.
  4. Emit, don't screenshot.The boards are run-length encoded into <rect> rows inside a second sprite, so the pixel edition stays inline SVG: it scales, it themes, and it adds no image requests. PNGs are a by-product, including the contact sheet above.
  5. Prove the colours, not just the markup.A clone behind <use> is invisible to document CSS, so the first version painted black blobs. Shapes now carry presentation attributes driven by custom properties, and the checker asserts by counting rendered cyan / amber / violet pixels from screenshots rather than trusting the source.

All 22 glyphs at 5× scale, 3.6 KB. Per-glyph provenance — shapes read, pixels lit, colours used — is written to a manifest next to the generator.

Reading it on the rest of the site

Pixel mode is a site-wide switch, not a separate build: the nav's ◼ pixel button (or ?pixel=1 on any URL) retargets every icon reference and turns on the pixel stylesheet — hard borders, drop-shadow instead of blur, a 4-pixel substrate grid. Your choice is remembered, and every page keeps working with the toggle off or JavaScript disabled.

The thesis

Three things must be true before an AI output enters an actuarial decision

Everything I publish builds or tests one of these. Where a project is only a demonstration, I say so out loud — a portfolio that cannot separate evidence from intention is worth nothing to the person who has to sign.

01 · MEASUREMENTGenerate the truth; never curate it

A curated answer key drifts and cannot be regenerated when the test grows. Both studies start from data whose ground truth was planted by a deterministic generator, scored by a scorer that counts false alarms rather than flattering the model.

02 · GOVERNANCEEvery claim ships the bytes behind it

Frozen harness snapshots and prompt hashes, decisions logged in JSONL, per-pass manifests, sealed truth per scenario. A number without the instrument that produced it is an anecdote.

03 · ACCOUNTABILITYAgents propose; a named human decides

Escalation thresholds, permissions and conservatism belong in the architecture, not in the prompt wording. Stability is often bought with a risk-appetite decision, and somebody should sign that.

 Study 02 · Underwriting decisions

The same applicant, a hundred times

Repeated-invocation testing of a multi-agent underwriting engine: variance concentrates exactly at the decision boundary, temperature changes the decision and not merely the spread, and a most-conservative combine rule absorbed an agent's ~20 % variance down to zero across 100 of 100 runs.

Design learnings

What building this taught me

Each of these cost me a rebuild. They are listed with the repository that taught them, because a lesson without a source is a slogan.

Data generatorPlant controls on the actuals only

Expected values stay on the pricing basis, so every deviation is signal you put there deliberately — and can prove.

Experience BenchFreeze the instrument before you quote it

Harness snapshots, prompt hashes, corpus manifests. Otherwise the next run compares against something that no longer exists.

Experience BenchTwo failure modes, two metrics

A miss and an invention are different diseases. Blending them hid both — and the cure that helped one made the other worse.

UnderwriterRules first, model second, human last

The deterministic engine answers everything it can; the LLM only handles what rules cannot settle. That is what makes residual variance attributable.

UnderwriterThe combine rule is a control surface

Architecture moved variance from ~20 % to 0 % — and quietly bought conservatism with it. Name the trade, then sign it.

Analysis DashboardThe audit trail is the feature

Pipeline audit, session persistence, re-runnable steps: an answer anyone can re-derive is what makes analysis survive an audit.

Standard InquirerRetrieval beats memory

Compliance questions must cite standards from a knowledge base, not a model's recollection of them.

LLM_Status_WatchStdlib-only is a deployment feature

No pip, no jq, nothing to break on a Pi in a corner. A shared local model is a server with a queue — treat it like one.

Craft reposWrite the question before the sweep

Pre-register, report the noise floor, and never generate a question you cannot defend.

The journey

Broken time forced a method

All of this was built in the gaps — forty minutes between a full-time job and childcare. That constraint is not a confession, it is the origin of the engineering: work that can be delegated, left alone and picked up later by a version of me who has forgotten everything. It happens to be the same furniture a model-risk manager asks to see.

01 · DELEGATE THE LOOPNot the line

Hand over a contract, an execution surface, an artefact trail and a stopping rule. The underwriter's own code was written by the local model it studies; the benchmark's harness was built by an agent on a third model so no model tuned its own exam.

02 · STEER THE BLACK BOXVerify behaviour, never inspect internals

One hypothesis, one edit, re-check the neighbours, keep or revert, snapshot the bytes. The held-out split is a wall, not a feedback channel — and the levers that moved measured behaviour were all outside the model.

03 · COME BACK AS THE CHECKPOINTAsynchronous HITL

Write the handoff, launch the unattended run, leave the room, get pinged when the shared server frees up, then decide keep or revert from the artefacts. The best pass ships — not the last one.
